# Plain-Language Glossary

## Storyboard

A simple visual plan for the main moments in the clip.

## Keyframe

An important still image. In an AI video workflow, a start keyframe and end keyframe can guide the movement of one short clip.

## First Cut

The first watchable version of the video. It is made for review, not perfection.

## B-Roll

Extra footage that supports the main story: hands, places, objects, weather, roads, crowds, instruments, textures or small details.

## Lip-Sync

Mouth movement matching the sung or spoken words. It can be technically fiddly, so many clips use performance, symbolism, quick cuts or off-camera moments instead.

## Handoff

A clean file that lets someone else continue the work without guessing the brief.

## Public/Private Boundary

The line between what can be shared and what should stay private, blurred, symbolic, consent-checked or offline.
